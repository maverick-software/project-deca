Server setup

One FastAPI process hosts every agent (a 204M-parameter neural cognitive stack per agent), the REST control surface, and the per-agent cycle WebSocket. A body (MuJoCo adapter or any custom client) connects over the WebSocket and streams observations; the mind streams motor actions back.

# 1. the mind server (port 8765)
.venv\Scripts\python.exe -m uvicorn decadic.api.app:app --host 127.0.0.1 --port 8765

# 2. the dashboard (Vite dev server, port 5173)
cd dashboard && npm run dev

# 3. a body (MuJoCo humanoid; runs until stopped; --view opens the native viewer)
.venv\Scripts\python.exe scripts\mujoco_decadic_adapter.py --port 8765 --view

# or: the all-in-one instrumented run (clean env, teardown, verdict summary)
powershell -ExecutionPolicy Bypass -File scripts\run_body_diag.ps1 -GraphBackend kuzu -Seconds 3600 -Watch
CORS defaults allow localhost:8080 and localhost:5173 (override with DECADIC_CORS_ORIGINS). Base URL below is assumed http://127.0.0.1:8765.

Quick start

# create a mind (full 204M preset by default; "tiny" for CPU/tests)
curl -X POST "http://127.0.0.1:8765/agent"
# => {"agent_id": "83dc95e8-..."}

# watch its vitals
curl "http://127.0.0.1:8765/agent/{id}/state"
curl "http://127.0.0.1:8765/agent/{id}/metrics"
# minimal Python body: stream observations, receive actions
import asyncio, json, websockets

async def body(aid):
    async with websockets.connect(f"ws://127.0.0.1:8765/agent/{aid}/cycle",
                                  max_size=None, ping_interval=None) as ws:
        async def listen():
            async for raw in ws:
                msg = json.loads(raw)
                if msg.get("type") == "body_command":  # control lane (give_*, stances...)
                    print("command:", msg["command"])
                elif "action" in msg:                   # motor output, one per cycle
                    ctrl = msg["action"]["parameters"].get("ctrl")  # 21 PD targets in [-1,1]
        asyncio.create_task(listen())
        while True:
            await ws.send(json.dumps({
                "timestamp": "2026-07-06T12:00:00Z",
                "proprioception": {"position":[0,0,1.3], "orientation":[0,0,0],
                                   "velocity":[0,0,0], "current_action":"idle"},
                "events": [],
            }))
            await asyncio.sleep(0.1)

Agent lifecycle

POST/agent?preset=tiny|full

Create an agent (mind). Builds the neural stack (all validated faculties ON by default, new capabilities zero-init so a fresh agent is birth-identical). Returns agent_id.

GET/agents

List live agents with cycle counts and status. One brain per server for measurement runs — a second agent shares GPU/CPU/IO and confounds every number.

DELETE/agent/{agent_id}

Terminate and remove the agent.

POST/agent/{agent_id}/pause  /  /agent/{agent_id}/resume

Suspend / resume the cycle worker (state preserved; body goes limp on command drought).

POST/agent/{agent_id}/reset

Rebuild the mind from its creation-time flags (fresh weights, memory cleared).

POST/agent/{agent_id}/preset?preset=

Switch neural architecture preset (rebuilds the brain; interface dims stay frozen across presets).

POST/agent/{agent_id}/revive?restore_to=

Bring a dead (viability-zero) agent back, optionally restoring reservoirs to a level.

GET/settings/agent-defaults  ·  POST/settings/agent-defaults

Read / partially update the defaults applied to new agents: plasticity flags (plasticity_enabled, sparse_enabled, growth_enabled, plasticity_alpha, sparse_density, max_neurons, growable_hidden_ceiling) and faculties (perception_feedback, self_model_feedback, predictive_affect, represented_self, perception_mode, encoder_mode). Existing agents are untouched.

GET/debug/tasks

Live asyncio task inventory (debugging stalls/orphans).

Cycle WebSocket — the mind↔body contract

WS/agent/{agent_id}/cycle

The body streams observations in; the mind streams actions and telemetry out. One decadic cycle runs per integrated observation. Two outbound lanes share the socket: the control lane (priority: body_command, death) and the telemetry/action lane.

Client discipline (from scripts/mujoco_decadic_adapter.py): connect with max_size=None, ping_interval=None (viewer stalls false-trip keepalive), reconnect with backoff to the same agent_id on socket resets (the brain persists server-side; DECADIC_BODY_MAX_RECONNECTS), and treat a command drought > DECADIC_BODY_COMMAND_STALE_S as "go limp".

Observation & telemetry

GET/agent/{agent_id}/state

Full state snapshot: State Bus A–F, vitals (viability/pain/pleasure), priority label, working memory, perceptual state, LTM graph snapshot — what the dashboard renders.

GET/agent/{agent_id}/metrics

The telemetry dump: cycle timings, pc-loss/EMA, plasticity & growth governance (growth_events, growth_blocked_reason), successor value (incentive salience — must climb off ~0 for foraging), store health (graph_flush_*, graph_writes_deferred, graph_coalesce_dedup_rows, ltm_match_ms, commit_lag_ms), reservoirs, goal status.

GET/agent/{agent_id}/explain?history=&counterfactuals=&attribution=

Cognitive trace: per-cycle "why" (drive contributions, counterfactual action values, attributions).

GET/agent/{agent_id}/discovery

Discovered-perception scoreboard: slots, agency ("mine") classification, egocentric graph.

GET/agent/{agent_id}/vision?camera=  ·  GET/agent/{agent_id}/audio

Latest egocentric frame (PNG) / audio window — dashboard taps, not cognition inputs.

GET/agent/{agent_id}/brain/topology  ·  /agent/{agent_id}/brain/landscape

3D brain map (blocks, awake neurons, strongest weights, live activations) · loss-landscape slice (needs DECADIC_LANDSCAPE_ENABLED=1).

GET/agent/{agent_id}/debug/stage-sessions?limit=24

Recent per-stage timing sessions (the decadic ring's data).

GET/body/stances  ·  POST/agent/{agent_id}/body/stance?name=

List / apply body stances (stand, crawl scaffolds...) via the control lane.

Memory

GET/agent/{agent_id}/memory?limit=50

Recent episodic records (cycle, summary, salience).

GET/agent/{agent_id}/memory/similar?limit=

Nearest episodes to the current state-bus query vector (the recall the mind itself uses).

Backends (defaults): episodic = LanceDB, long-term graph = Kuzu with the WS4B off-lock flusher + write governance (per-key throttle DECADIC_KUZU_WRITE_MIN_CYCLES=25, keyed coalesce-dedup). Memory is the read model; the stores are durability.

Homeostasis & provisioning

POST/agent/{agent_id}/give?resource=water|food|medical_kit&mode=&amount=

Provision the agent. The mode ladder is a curriculum — how much of the approach must be earned:

modebehavioruse for
admininstant reservoir credit (no body)rescue / testing
direct | visual_directitem shown in view, delivered to the head, auto-consumedobject→relief association only (no approach learned)
within_reach | reachplaced ~0.6 m ahead (DECADIC_BODY_REACH_DISTANCE) — a lean/step earns itbootstrapping act→relief (the value learner's food)
nearplaced ~1.6 m ahead — a full approachforaging once reaching exists

Consumption is contact-gated by default (DECADIC_BODY_CONSUME_MODE=contact): a body part must come within DECADIC_BODY_CONTACT_RADIUS (0.30 m) of the item — proximity alone no longer feeds. Direct delivery is exempt. Responses include supervised and the grant cycle (pairs with the nourishment log line for grant→retrieval analysis: scripts/analyze_feeding.py).

Against a standalone body (diag harness), set DECADIC_ALLOW_EXTERNAL_BODY_PROVISION=1 or non-admin modes return 409 ("no running body"). The harness sets it automatically.

Body control

POST/agent/{agent_id}/body/recenter · reset_braces · braces?enabled= · movement_hold?enabled= · manual_auto_reset?enabled= · npc?paused= · viewer?open=

All queue a control-lane body_command to the connected body: recenter the humanoid, manage the joint-brace orthosis, hold/loop a movement, auto-reset motion stances after falls, freeze/resume the parent/crowd NPCs, open/close the native MuJoCo viewer window.

Environment (server-managed body)

GET/environment  ·  POST/environment  ·  POST/environment/pause|resume|stop  ·  DELETE/environment

Start/manage a supervised scenario: the server spawns its own MuJoCo body and a new agent. Body: {"elements":["food","water","medical_kit","house","obstacles","npc","crowd"], "vision":true,"audio":false,"braces":false,"replace":false,"preset":null, "curriculum":{"kind":"forage","place_every_s":8,"rescue_floor":12,"rescue_to":35}}. The forage curriculum places the most-depleted resource within reach on a tick and rescues any reservoir below the floor — the survival net for metabolic learning runs. pause freezes physics and the mind in lockstep.

Starting an environment while another agent is running adds a second 204M brain to the same GPU — the diag harness will warn in red. Don't do it during measurement runs.

Checkpoints (in-place)

POST/agent/{agent_id}/checkpoint  ·  POST/agent/{agent_id}/restore

Snapshot / restore the same agent in place (brain weights, state bus, viability, memory stores via quiesced backup). Returns the checkpoint path / restored payload.

Saved agents (library)

POST/agent/{agent_id}/savebody: {name, notes}

Save the full agent (manifest + state + brain.pt + memory snapshots; faculties self-described in the manifest) into the durable library.

GET/saved-agents  ·  POST/saved-agents/{save_id}/load  ·  DELETE/saved-agents/{save_id}

List, load (spawns a NEW agent from the save — memory fidelity included), delete. Loading is checkpoint-compatible across faculty additions (shape-filtered; new zero-init heads keep fresh init).

Agent presets

GET/agent-presets  ·  POST/agent-presets  ·  DELETE/agent-presets/{preset_id}

Named scenario/body/config bundles for the dashboard dropdown (seeded with built-ins).

Skill Dojo (training curricula)

GET/dojo/skills · /dojo/skills/{skill_id}  ·  POST/dojo/skills/upload  ·  DELETE/dojo/skills/{skill_id}

Built-in + uploaded skill curricula (e.g. teacher-guided standing → perturbation recovery → autonomy). Teacher hints enter only replay/consolidation metadata — the live loop stays self-supervised.

Run a skill: phased criteria (e.g. resource_relief_events trend>=1), periodic body commands, assist fading, per-phase config overrides; phase forces a phase transition.

Voice & hearing (WS6 speech loop)

organcontinuous auditory intake (server-side, always on by default)

Hearing is a property of the body, not of the client: an always-on AudioIntake service (decadic/audio/intake.py) captures continuously — system microphone (mic) or the simulated mixing bus (bus) — into a ring buffer, and every observation that arrives WITHOUT audio is given the freshest ≤250 ms chunk at ingest (pcm16-base64, the schema the frozen Whisper path already decodes). Client-supplied audio always wins, so recorded scenarios stay byte-reproducible. An energy silence gate (with one-chunk hysteresis for word tails) keeps quiet rooms off the GPU. Live mic capture needs pip install sounddevice; without it the service degrades to inert and the bus/loopback path still works.

organvoice output (cognition-driven, silent at birth)

The stack emits an 8-dim articulatory vector voice_u (f0, energy, voicing, formants) from the same policy latent as the motor heads — the action dict carries it as parameters.voice beside ctrl. Each cycle the runtime renders it through a formant synthesizer (decadic/audio/vocal_tract.py, click-free interpolation, ~one cycle-period of 16 kHz samples), always mixes it back into the intake (self-hearing — the loop that makes babbling, vocal agency, and imitation learnable), and tees it to the host speakers when a device exists. The head is zero-initialized: a newborn agent is silent until learning moves it; old checkpoints load into voice-on builds mute. Per-cycle stats surface in agent metrics (audio_intake, voice_params, voice_playback).
