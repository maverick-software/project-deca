The architecture

A continuous loop of cognition — not one forward pass.

Deca runs an original, multi-stage cognitive cycle as a live, asynchronous process: perception flows through to action, and a persistent inner state is carried across every cycle. It's a genuine cognitive architecture — not a single neural network, and not a prompted language model.

Sense→ Integrate→ Evaluate→ Decide→ Act→ Remember↺

Every pass folds its outcome back into memory and a persistent self-model, feeding the next cycle — so behavior develops over time instead of staying fixed. The cycle never stops.

What's built

A working system — running today, end to end.

Not a slide deck. A live, embodied agent that perceives, learns, and acts from its own motivation.

🦾

Embodied

A physical humanoid in simulation — proprioception, touch, vision, and audio. The architecture is body-agnostic: any world or robot can become its body.

🔄

Self-supervised

Predictive coding and forward-model error drive learning every cycle. No labels, no human feedback — it learns by predicting its world and being wrong.

🔥

Intrinsic drive

Two innate motivations: homeostatic survival (hunger, thirst, integrity) and need-gated curiosity that rewards real learning progress. Everything else is learned.

🧠

Brain-like memory

Fast episodic memory, a persistent self-indexed knowledge graph, and offline replay consolidation — a complementary-learning-systems design, the way biological memory works.

⛔

No LLM in the core

The cognitive core is custom neural modules, not a pretrained language model. Language, if added, is a faculty — never the seat of cognition.

👁️

Observable

A live dashboard renders the real network, the loss landscape, the self-model graph, and a per-cycle "why" trace. You can watch it think.

Why a self-driven mind wins

You don't train it for every task. You give it a goal — and it improves toward it.

Conventional models must be trained, separately and exhaustively, on every capability you want them to have. A self-driven mind learns from its own experience: point it at an objective, and it tunes itself to get better at it — the way a person grows into a role.

🎯

Tune it to any goal

The same architecture can be pointed at different objectives. Its own drives and learning adapt it toward whatever goal it's given — no new model, no new training pipeline per task.

📈

It improves itself

It gets better from its own experience, continuously. You don't have to anticipate and label every situation it will face — it learns the ones it actually encounters.

♾️

It compounds

Because it learns online and never freezes, competence accumulates with use. The longer it pursues a goal, the better it gets — instead of being capped at training time.

One adaptable mind, tuned toward your goal — instead of an ever-growing fleet of narrowly-trained models, each built and retrained from scratch.
